# Bundled Node.js runtime

This directory contains the official Windows x64 Node.js runtime used by the
Excel configuration exporter. It allows the exporter to run on a clean Windows
computer without installing Node.js, pnpm, Cursor, or Cocos Creator.

- Version: Node.js v24.21.0 (Krypton LTS)
- Platform: Windows x64
- Download: https://nodejs.org/dist/v24.21.0/node-v24.21.0-win-x64.zip
