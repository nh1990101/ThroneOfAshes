# 技能表现编辑器

图文使用说明与交互演示：[打开 guide.html](guide.html)。可直接双击 `guide.html` 离线阅读并体验演示；更新服务后，关闭旧服务并重新运行 `start.bat`，也可从编辑器底部“快捷键 / 使用说明”打开。

HTML / CSS / 原生 JavaScript + Canvas 2D，本地 Node.js 服务读取项目资源和 Excel。无需构建，也不需要安装新的前端依赖。

## 启动

双击此目录的 `start.bat`，然后用 Chrome 或 Edge 打开 <http://127.0.0.1:8766/>。

也可以在项目根目录执行：

```powershell
node SkillEditor/server.cjs
```

需要 Node.js 18 或以上，以及项目现有的 `node_modules/jszip`。本地服务只监听 `127.0.0.1`，不改原始图片、Excel 或游戏脚本。保存配置会写入项目的 `assets/remote/Res/Config/Skill/技能ID.json`，例如技能 ID 为 `1001` 时保存为 `1001.json`。技能 ID 必填，并且必须是合法的文件名；同 ID 技能再次保存时更新同一文件。

更新 `server.cjs` 后需要关闭旧服务并重新运行 `start.bat`。当前保存服务会按 `core.mjs` 内容版本加载参数解析器，之后修改该文件无需重启服务。保存成功前会回读原始 JSON，检查强制移动的 `moveType` 与 `targetCell`，发现字段丢失时显示错误并保留草稿。

如果端口被占用，可以在 PowerShell 中为本次启动指定端口：

```powershell
$env:SKILL_EDITOR_PORT = '8767'
node SkillEditor/server.cjs
```

此时打开 <http://127.0.0.1:8767/>。不要直接通过 `file://` 双击 HTML：浏览器无法自行枚举项目目录或读取 Excel。

## 当前项目资源情况

- 单位表：`sharedata/excel/D-单位表(UnitData).xlsx`，读取 `UnitData` 工作表及其 `id`、`name`、`ch_key`、`animation_name` 等字段。
- 角色图集：`assets/remote/Res/Battle/UnitResAtlas`，当前扫描到 36 个图集。
- 技能特效：`assets/remote/Res/Battle/Skill`。添加资源后点击资源库的刷新按钮即可重新扫描。
- 地图格子：`AtlasSource/Battle/ui_battle_select_frame.png`。
- 场景背景：`assets/remote/Res/SingleImage/Battle/ui_battle_bg.jpg`，按 cover 方式铺满预览区域。

单位图集读取配置表的 `animation_name` 字段，例如 `Res/Battle/UnitResAtlas/1001` 对应图集 `1001`。放置单位时自动选择对应图集，也可手动修改；映射保存在 JSON 的 `resourceMappings` 中。字段为空或图集不存在时会明确提示，需手动选择对应图集。

图集支持 Cocos / TexturePacker plist format 2、3，含旋转帧、裁边与位置偏移。也支持技能目录下由独立 PNG 帧组成的子目录，例如 `Skill/fireball/001.png`、`002.png`，此时特效 ID 为 `fireball`。图集或帧名按数字自然排序。PNG 序列要求按原始画布对齐；无法从独立 PNG 推断已丢失的裁边偏移。

## 操作流程

点击顶部“新建”，输入技能 ID 后创建空白技能；未填写或 ID 不合法时不能创建。取消或关闭弹窗会保留当前技能。旧草稿或导入配置未设置 ID 时，需要在技能设置中补全后才能保存。

1. 点击空地图格子，在弹窗选择单位 ID、图集和攻击者 / 受击者；点击已放置的角色，在右侧修改参数。受击者默认左右镜像并保持正立。
2. 左侧资源使用虚拟滚动列表。选中特效可预览动画，双击或点击“加入特效轨道”可创建特效节点。
3. 点击“新建轨道”，选择六类节点之一：施法者行为、受击者行为、技能特效、特效飞行、伤害、强制移动。每条轨道一个节点及一个触发关键帧。
4. 在右侧设置节点参数；角色动作以逐帧缩略图平铺到时间轴。每条动作可以单独设置 FPS，时间标尺始终以毫秒计。
5. 横向拖动节点设置绝对时间；拖到角色动作帧建立帧关联，拖到飞行轨道末尾的“飞行结束”菱形节点建立结束关联。也可在右侧“关联时间节点”中选择来源。修改角色 FPS、飞行速度或起终点后，关联时间自动重算。按住 Alt 拖动可临时跳过吸附。
6. 创建飞行前，先选择场景或时间轴里的一个特效实例。飞行引用特效轨道实例 ID，同一特效资源可创建多个互不干扰的实例。
7. 播放 / 暂停，或拖动时间标尺检查任意时刻。停止时返回 0 ms。支持循环、预览倍速、时间轴缩放、画面缩放和平移。
8. 保存 JSON 到 `assets/remote/Res/Config/Skill/技能ID.json`；导入相同格式 JSON 可还原单位、图集映射、所有节点参数和帧关联。输入技能 ID 并确认新建后清空场景和轨道，支持撤销。

点击时间轴工具栏中的总时长，可直接打开“技能设置 → 流程时长”。默认“自动”模式，以最后一个启用节点的播放结束时间作为技能终点，不再固定至少 3 秒。需要保留更长的收尾时间时，切换到“手动”并填写最小时长（毫秒）；若节点结束更晚，仍会延长到节点完整播放结束。

首次可点击“载入操作示例”，了解多段伤害、帧关联和击退。示例中的图集映射仅用于演示，可在属性面板修改。

## 行为约定

- 角色动作沿用 `assets/script/GamePlay/Battle/UnitBase.ts` 的零基图集区间：站立 0–5，移动 6–8，受击 9–10，死亡 11–13，攻击从 14 到末帧。角色默认 10 FPS；特效默认 24 FPS，可分别调整。
- 施法者、受击者的 `params.action` 保存为 `GameEnum.ts` 的 `UNIT_ACTION` 数值：`IDLE=0`、`MOVE=1`、`BE_HIT=2`、`DEAD=3`、`ATTACK=4`，不使用边界值 `MAX`。旧配置的 `idle/move/hit/dead/attack` 字符串仍支持导入，重新保存时转换为枚举数值；游戏配置加载函数也兼容这些旧值。
- 时间轴的“第 N 帧”从 1 开始，表示当前动作中的相对帧。触发时间 = 源轨道开始时间 + `(N - 1) × 1000 / FPS` + 附加毫秒偏移。
- 自动时长取所有启用节点的“实际触发时间 + 播放时长”的最大值，与轨道排列顺序无关；修改节点时间、帧率、速度或飞行距离后重新计算。循环动画按一轮计算，空技能或全部禁用时总时长为 0，暂停播放。时间尺保留可编辑的空白区域，总时长显示与播放终点按实际流程计算。
- 非循环角色动作结束后回到站立；死亡动作保持最后一帧。同一单位同时开始多个角色动作时，轨道列表中后面的动作优先。
- 关闭“循环播放特效”时显示“持续时间 / ms”，可填写 1–120000 毫秒；留空沿用一轮动画时长。填写后按该时长隐藏特效，短于一轮时提前结束，长于一轮时保持最后一帧；修改帧率或速度倍率不会改变已填写的持续时间。开启循环后隐藏并忽略该值，关闭循环会恢复之前填写的值。时间轴、流程总时长及导出的 `resolved` 同步使用该时长。
- “播放技能特效”的“是否多目标”默认关闭，循环与非循环时均可设置。保存为 `params.multiTarget`，供运行时判断是否为每个敌人分别创建一个特效；开启为 `true`，关闭为 `false`，旧配置缺失时按关闭处理。
- 未手动指定百分比的伤害节点平均分摊剩余百分比；全部自动时每段为 `100 / 节点数`。手动总占比超过 100% 或最终总和不足 100% 都有配置提示。禁用轨道不计入分摊。伤害数值是编辑器预览用的“预览总伤害”，游戏内实际结算需由战斗系统消费节点。
- 伤害在节点开始时结算一次，伤害数字表现持续 700 ms。伤害轨道宽度、流程总时长和导出的 `resolved.nodes[].durationMs` 均包含这段播放时间；例如最后一个伤害节点从 1000 ms 开始，流程至少播放至 1700 ms，完整播放后结束。
- 强制移动支持四种类型：`1` 按移动单位水平朝向的反方向移动；`2` 按施法者指向移动单位的向量，选择最近的六边形方向移动；`3` 固定六方向（旧配置默认）；`4` 全局移动，直接向指定目标格子移动。前三种使用移动格数，全局移动只使用目标格子坐标，沿起终点直线移动，不绕障碍。向量模式在缺少施法者或两者位置重合时不移动。
- 强制移动预览默认忽略占用，允许单位重叠；可在技能设置切换为遇到占用停步，移动始终限制在 7×7 地图边界。耗时 0 ms 为瞬移，设置大于 0 的耗时可滑动表现。移动期间立即预占终点格。游戏内在开始时检查整条路径，受阻时按回弹参数返回原格；编辑器预览使用技能设置中的碰撞规则。
- 格子 `q,r` 以左下角第一个格子为 `(0,0)`，`q` 向右递增、`r` 向上递增，奇数行右移半格。位置可选择施法者、受击者或自定义像素坐标；自定义可相对施法者、受击者或地图中心，X 向右、Y 向上。绘制时转换为 Canvas 的 Y 向下坐标。
- 单位动画按素材原始中心锚点对齐格子坐标，不添加脚底对齐或其他额外位置偏移；保留 plist 裁边数据以还原原始帧位置，点击区域随实际显示的帧计算。
- 自动位置默认取场景里第一个相应角色类型的单位；角色行为、伤害、位移可显式选择场景单位实例。
- 特效自动层级按屏幕 Y 从上到下绘制，对应 Cocos Y 越小越靠前；同 Y 时攻击方在受击方前。最上层和最下层可覆盖自动排序。
- 飞行按触发时的起终点快照直线匀速移动，时长 = 距离 / 每秒像素速度；后续目标位移不会改变已发出的飞行轨迹。未指定持续时间的特效播完但仍在飞行时保持最后一帧；指定持续时间后以该时长为限，即使仍在飞行也会隐藏。也可以开启特效循环。勾选“到达终点后隐藏特效”时仍会在到达后提前隐藏。
- 飞行的“起始点”和“结束点”各有独立的位置偏移 X/Y（像素），施法者、被攻击者、自定义位置均可设置。默认均为 0；X 向右、Y 向上，按世界方向叠加在所选位置上。修改偏移后，预览路径、飞行朝向、飞行时长及结束关联自动重算。
- 每条飞行轨道自动显示一个“飞行结束”节点，时间为实际开始时间加飞行时长。将其他行为节点拖到该菱形附近即可吸附并高亮，松开后保存关联；源飞行时间变化后，关联行为会跟随结束点调整。属性面板可设置相对结束点的毫秒偏移，删除源飞行时保留关联行为最后计算出的绝对时间。
- 飞行节点的“是否与目标点朝向一致”默认关闭；开启后特效按起点指向终点的方向旋转，以素材朝右为 0°，起终点重合时保持 0°。该选项随 JSON 保存。
- 时间游标每次都从配置重建场景，无需从头播放才能定位；禁用轨道不执行行为，但其帧关联仍保持可编辑，并显示关联提示。

## 快捷键与恢复

| 操作 | 快捷键 |
| --- | --- |
| 播放 / 暂停 | Space |
| 10 ms 步进 | ← / → |
| 默认角色一帧步进 | Shift + ← / → |
| 回到开始 | Home |
| 删除当前单位或轨道 | Delete |
| 导出 JSON | Ctrl + S |
| 撤销 / 重做 | Ctrl + Z / Ctrl + Shift + Z，或 Ctrl + Y |
| 暂时取消吸附 | Alt + 拖动节点 |
| 场景缩放 / 平移 | 滚轮 / 中键拖动 |

在地图与时间轴之间上下拖动分隔线，可调整时间轴高度。特效实例可直接在场景中拖动以更新偏移。

草稿自动保存在当前浏览器、当前端口的 localStorage 中；刷新页面自动恢复。保留重要配置请使用 JSON 导出，清除浏览器站点数据会清除本地草稿。撤销历史只在当前页面会话中保留，最多 80 步。

## JSON 格式与游戏接入

根节点使用 `format: "RPGCore.SkillPresentation"`、`schemaVersion: 1`，包含 `skillId`、`name`、`settings`、`scene`、`resourceMappings`、`tracks`。每条轨道包含 `id`、`type`、`name`、`enabled`、`startMs`、`binding` 和该类型的 `params`。

`settings.durationMode` 为 `"auto"`（默认）或 `"manual"`，旧配置缺失时按自动模式处理。根字段 `durationMs` 仅在手动模式中作为最小时长；最终流程时长始终写入 `resolved.durationMs`，与编辑器播放终点一致。

特效轨道的 `params.durationMs` 保存非循环持续时间（毫秒），`null` 或旧配置缺失表示自动按一轮动画计算；`params.loop` 为 `true` 时忽略此值。该字段与根节点的流程最小时长相互独立。

特效轨道的 `params.multiTarget` 为布尔值，`true` 表示每个敌人一个特效，`false` 表示单个特效；旧配置缺失时导入补为 `false`。此参数独立于循环和持续时间，供战斗运行时创建特效实例时读取。

`binding` 为 `null` 时使用绝对时间；动作帧关联保持 `{ "trackId": "动作轨道ID", "frame": 1, "offsetMs": 0 }`；飞行结束关联为 `{ "trackId": "飞行轨道ID", "anchor": "end", "offsetMs": 0 }`。飞行结束点是派生时间节点，不新增独立轨道。`resolved.nodes` 会保存关联后计算出的实际触发时间。

`scene.coordinateOrigin` 固定保存为 `"bottom-left"`。导入没有此字段或标为 `"top-left"` 的旧配置时，自动转换单位和强制移动格子的行号，保持原来的画面位置与移动方向；旧草稿同样兼容。飞行的 `params.alignToTarget` 保存朝向开关，旧配置未包含此字段时按关闭处理。

强制移动的 `params.moveType` 保存数值 `1–4`，旧配置缺失时补为 `3`（固定方向）。`params.targetCell` 保存全局移动的目标地图格子，格式为 `{ "q": 0, "r": 0 }`；`moveType: 4` 必须包含有效目标格子，旧版左上角坐标导入时也会转换目标行号。原 `params.cell` 继续仅供编辑器预览选取移动单位，游戏内通过 `targetUID` 获取实际受击单位，不使用此字段定位目标格子。

飞行的 `params.startOffset`、`params.endOffset` 分别保存起终点的世界像素偏移，格式均为 `{ "x": 0, "y": 0 }`。旧配置缺失时补零；自定义位置的原坐标与偏移相加。游戏飞行节点也会读取这两个字段，在触发时记录偏移后的起终点。

导出额外包含 `resolved`：最终时长、各节点已计算的毫秒触发时间 / 时长和伤害百分比。游戏可使用这些结果执行，也可以按 `binding` 重算。导入以原始参数为准，忽略 `resolved`，防止派生值过期。`resourceMappings` 的键是单位配置 ID，值是图集资源 ID，例如 `{"110010":"1001"}`，示例不代表真实美术对应关系。

强制移动由 Cocos 战斗系统调度，运行时已消费 `moveType` 和 `targetCell`。方向、目标格及路径可移动性均在动作开始时确定，动画播放途中不重新判断；受阻时使用配置的回弹距离和耗时返回原格。

## 目录与文件

- `start.bat`：启动本地服务。
- `index.html` / `style.css`：界面与布局。
- `app.mjs`：交互、虚拟列表、Canvas 预览、时间轴与属性面板。
- `core.mjs`：纯数据模型、确定性时间求值、行为采样、导入导出校验。
- `sprites.mjs`：图集解码、旋转帧、裁边偏移和缩略图缓存。
- `resources.cjs`：Excel / plist 解析与资源扫描。
- `server.cjs`：本地资源 HTTP 服务及固定目录的 JSON 保存接口。
- `guide.html`：可离线打开的图文说明、交互演示及示例 JSON 下载。
- `exports/`：保留的历史技能配置和模板，可通过“导入 JSON”使用；当前保存位置为 `assets/remote/Res/Config/Skill/技能ID.json`。
