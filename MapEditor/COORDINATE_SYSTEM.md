# 地图编辑器坐标系统说明

## 坐标系统
地图编辑器使用**左下角坐标系**，与Cocos游戏引擎保持一致。

### 世界坐标（像素坐标）
- 原点：左下角 (0, 0)
- X轴：从左到右递增
- Y轴：从下到上递增
- 单位：像素 (px)

### 格子坐标
- 原点：左下角 (0, 0)
- X轴：从左到右递增
- Y轴：从下到上递增
- 单位：格子 (grid)

## 坐标转换关系

### 格子坐标 → 世界坐标
```javascript
worldX = gridX * gridWidth
worldY = mapPixelHeight - (gridY + 1) * gridHeight
```

### 世界坐标 → 格子坐标
```javascript
gridX = floor(worldX / gridWidth)
gridY = floor((mapPixelHeight - worldY) / gridHeight)
```

## 切图策略
从**左下角**开始切图（从下往上，从左往右）：
- 第一行（gridY=0）：地图图片的底部
- 最后一行（gridY=rows-1）：地图图片的顶部
- 黑边位置：顶部（高处），不影响地面视野

## UI显示
1. **底部信息栏**
   - `像素: (x, y)` - 鼠标位置的世界坐标（左下角原点）
   - `格子: (x, y)` - 鼠标位置的格子坐标（左下角原点）
   - `地图: WxH格 (WxHpx)` - 地图尺寸

2. **物体属性面板**
   - `位置格子 X/Y` - 物体所在格子坐标（只读）
   - `占据格子 X/Y` - 物体占据的格子数量（可编辑）
   - `偏移像素 X/Y` - 物体在格子内的像素偏移（可编辑）

## 注意事项
- 所有坐标都基于左下角原点
- Y轴向上递增，与屏幕坐标（向下递增）相反
- 切图文件命名：`{col}_{row}.jpg`，row直接对应gridY
