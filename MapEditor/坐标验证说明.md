# 坐标系统验证说明

## 坐标系统定义

### 1. Cocos Creator 世界坐标系
- **原点位置**：左下角 (0, 0)
- **X轴方向**：向右递增
- **Y轴方向**：向上递增

### 2. 格子坐标系
- **原点位置**：左下角格子 (0, 0)
- **X轴方向**：向右递增
- **Y轴方向**：向上递增

### 3. Canvas 画布坐标系（内部渲染用）
- **原点位置**：左上角 (0, 0)
- **X轴方向**：向右递增
- **Y轴方向**：向下递增

---

## 坐标转换公式

### 格子坐标 → 世界坐标

```javascript
worldX = gridX * gridWidth
worldY = gridY * gridHeight
```

**示例**（假设格子大小为 64x32）：

| 格子坐标 | 世界坐标 | 说明 |
|---------|---------|------|
| (0, 0)  | (0, 0)   | 左下角第一个格子 |
| (1, 0)  | (64, 0)  | 右边一格 |
| (0, 1)  | (0, 32)  | 上面一格 |
| (1, 1)  | (64, 32) | 右上方格子 |

### 屏幕坐标 → 格子坐标

```javascript
// 1. 屏幕坐标转Canvas坐标
const canvasX = screenX - rect.left
const canvasY = screenY - rect.top

// 2. Canvas坐标转世界坐标（考虑缩放和偏移）
const worldX = (canvasX - offsetX) / scale
const worldY = (canvasY - offsetY) / scale

// 3. 世界坐标转格子坐标
// 注意：worldY是从画布顶部算起的，需要转换为从底部算起
const gridX = Math.floor(worldX / gridWidth)
const gridY = Math.floor((mapPixelHeight - worldY) / gridHeight)
```

## 验证方法

### 1. 鼠标移动到左下角

**预期结果**：
- 格子坐标：接近 `(0, 0)`
- 世界坐标：接近 `(0, 0)`

### 2. 鼠标移动到右下角

**预期结果**（假设地图32x32格，格子64x64像素）：
- 格子坐标：接近 `(31, 0)`
- 世界坐标：接近 `(1984, 0)`

### 3. 鼠标移动到左上角

**预期结果**：
- 格子坐标：接近 `(0, 31)`
- 世界坐标：接近 `(0, 1984)`

### 4. 鼠标移动到右上角

**预期结果**：
- 格子坐标：接近 `(31, 31)`
- 世界坐标：接近 `(1984, 1984)`

## 常见错误

### ❌ 错误公式

```javascript
// 这是错误的！会导致Y坐标倒置
worldY = mapPixelHeight - (gridY + 1) * gridHeight
```

**问题**：
- 格子(0,0)会得到 `worldY = mapPixelHeight - gridHeight`（接近顶部）
- 格子(0,maxY)会得到 `worldY = 0`（底部）
- Y坐标完全反了！

### ✅ 正确公式

```javascript
// 简单直接的线性转换
worldX = gridX * gridWidth
worldY = gridY * gridHeight
```

**优点**：
- 格子(0,0) → (0,0) ✓
- 格子Y递增时，世界Y也递增 ✓
- 符合Cocos坐标系 ✓

## 实际测试步骤

1. **刷新浏览器**（Ctrl+R）

2. **加载地图**（从大图切割或现有地图块）

3. **移动鼠标到地图四角**，观察底部信息栏：

   ```
   左下角：像素: (≈0, ≈0)      格子: (0, 0)
   右下角：像素: (≈W, ≈0)      格子: (maxX, 0)
   左上角：像素: (≈0, ≈H)      格子: (0, maxY)
   右上角：像素: (≈W, ≈H)      格子: (maxX, maxY)
   ```

4. **向上移动鼠标**，Y坐标应该递增（不是递减）

5. **向右移动鼠标**，X坐标应该递增

## 为什么需要这样转换？

### Cocos Creator 的坐标系统

在Cocos Creator中：
- 节点的 `position` 属性使用世界坐标
- 左下角为原点是游戏引擎的标准
- Y轴向上是为了符合数学直觉

### 地图编辑器的对应

- 地图的左下角格子 → 游戏中的 (0, 0)
- 放置的物体坐标 → 直接对应Cocos中的节点位置
- 保存的JSON → 游戏可以直接使用，无需转换

### 示例：放置一个NPC

```javascript
// 编辑器中：格子(5, 10)
gridX: 5
gridY: 10

// 转换为世界坐标：
worldX = 5 * 64 = 320
worldY = 10 * 32 = 320

// 游戏中创建节点：
npc.setPosition(320, 320)  // ✓ 正确的位置！
```

如果Y坐标公式错误，NPC在游戏中的位置就会上下颠倒！
