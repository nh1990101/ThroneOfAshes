## 技术实现

### 核心技术
- **File System Access API**: 实现浏览器直接读写本地文件系统
- **Canvas多层渲染**: 分层渲染地图、网格、标记、物体
- **SheetJS (xlsx.js)**: 在浏览器中解析Excel文件
- **拖放API**: 实现资源拖放到地图

## 使用流程

### 基础流程
1. 使用Chrome/Edge浏览器打开 `launcher.html`
2. 点击"选择资源目录"，选择 `assets/remote` 目录
3. 点击"新建地图"，填写配置并选择地图图片
4. 等待地图自动切割并保存
5. 点击"加载资源"，扫描MapObject目录
6. 进行地图标记和物体拖放
7. （可选）加载Excel表并随机生成物件
8. 点击"保存地图"导出配置

### 高级功能
- **地图标记**: 长按模式连续标记，单点模式精确标记
- **资源刷新点**: 同一格子可标记多个ID，颜色叠加
- **物体编辑**: 选中物体后在右侧面板编辑属性
- **随机生成**: 根据Excel配置和标记点智能生成物件

## 关键特性

### 1. 自动保存地图切块
- 不弹出文件保存对话框
- 直接写入到 `assets/remote/Res/Map/MapGrid/{MapID}/` 目录
- 自动创建目录结构

### 2. 逻辑格子 vs 地图切块
- **地图切块（512×512）**: 用于渲染优化，分块加载
- **逻辑格子（自定义）**: 用于行走逻辑和物体放置
- 两者独立，互不影响

### 3. 物体占据格子规则
- 以放置点为中心向四周扩展
- 例如：3×3的物体放在(5,5)，实际占据(4,5,6)×(4,5,6)

### 4. 多ID颜色叠加
- 每个资源ID有独特颜色（HSL色相均分）
- 同一格子多个ID时，颜色通过半透明叠加
- 显示数字表示ID数量

### 5. 智能生成检测
- 检查占据格子范围内所有格子
- 任何一个格子标记为不可移动，整个物体不生成
- 避免生成冲突

## 注意事项

### 浏览器要求
⚠️ **必须使用 Chrome 86+ 或 Edge 86+**
- Firefox 和 Safari 不支持 File System Access API
- 启动器页面会自动检测浏览器兼容性

### 文件系统权限
- 首次使用需要授权目录访问
- 浏览器会记住授权，后续自动恢复
- 如果权限丢失，重新点击"选择资源目录"

### Excel表格式
- 第3行为表头
- 第6行开始为数据
- 必须包含以下列：
  - 属性名（ID）
  - 中文索引（名称）
  - 类型
  - 地图占格子数（格式：x_y）
  - 地图显示的资源路径
  - 其它参数

### 资源路径规范
- 所有路径相对于 `assets/remote/` 目录
- 例如：`Res/Map/MapObject/Image/building_1`
- 自动处理 `.png`、`.jpg` 等扩展名

## 常见问题解答

**Q: 为什么选择HTML而不是Unity/Unreal编辑器？**  
A: HTML编辑器独立于游戏引擎，轻量级，跨平台，易于分享和协作。

**Q: 地图切割会覆盖原有文件吗？**  
A: 是的，切割时会覆盖同名文件。建议切割前备份原文件。

**Q: 可以在服务器上部署吗？**  
A: 可以，但File System Access API需要HTTPS环境（localhost除外）。

**Q: 配置文件可以版本控制吗？**  
A: 可以，配置文件是JSON格式，适合Git版本控制。

**Q: 如何批量处理多个地图？**  
A: 目前需要逐个处理。可以通过脚本批量转换Excel数据。
