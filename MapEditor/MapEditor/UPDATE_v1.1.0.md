# 地图编辑器 v1.1.0 更新说明

## ✨ 本次更新内容

### 1. 地图块目录选择改进 ✅
**问题**：之前需要手动输入路径
**改进**：
- 添加"选择目录"按钮
- 点击后弹出目录选择器
- 自动填充路径到输入框
- 输入框设为只读，防止手误修改

**使用方法**：
1. 新建地图时，选择"已切割的地图块目录"
2. 点击"选择目录"按钮
3. 选择包含地图块的目录（如 `MapGrid/Map1`）
4. 路径自动填充

---

### 2. 物体二次拖动功能 ✅
**问题**：物体放置后无法调整位置
**改进**：
- 点击地图上的物体可以选中
- 选中后显示黄色边框
- 按住物体可以拖动到新位置
- 拖动超过10像素自动更新位置（避免抖动）
- 点击空白处取消选中

**使用方法**：
1. 标记模式选择"无"
2. 点击地图上的物体（显示黄色边框）
3. 按住物体拖动到新位置
4. 松开鼠标完成移动

---

### 3. 属性面板显示优化 ✅
**问题**：属性面板一直显示，即使未选中物体
**改进**：
- 只有选中物体时才显示属性面板
- 点击空白处自动隐藏属性面板
- 拖动地图时不会误触选中

**效果**：
- 界面更简洁
- 编辑更直观
- 避免误操作

---

### 4. 资源刷新点ID显示 ✅
**问题**：之前只显示数量，不知道是哪些ID
**改进**：
- 单个ID：显示 `ID:1`
- 多个ID：显示 `ID:1+2`（第一个ID + 其他数量）
- 添加黑色描边，白色文字
- 字体大小随缩放自动调整

**示例**：
```
格子(10,10)标记了：
- ID=1
显示：ID:1

格子(15,15)标记了：
- ID=1
- ID=3  
- ID=5
显示：ID:1+2
```

---

### 5. 30种颜色色差优化 ✅
**问题**：原来的颜色色差太小，不容易区分
**改进**：
- 重新设计30种颜色
- 使用固定的色相、饱和度、明度组合
- 包含：纯红、橙色、黄色、黄绿、纯绿、青绿、青色、天蓝、纯蓝、紫色、品红等
- 每种颜色都有明显差异

3. 黄色 (60°)
4. 黄绿 (90°)

### 6. 随机生成物件功能改进 ✅
**问题**：之前生成的物体都在标记点固定位置，重叠在一起
**改进**：
- 在标记点周围 **±2格子范围内随机分布**
- 读取Excel的 `show_url` 字段作为资源路径
- 生成的物体效果与手动拖入完全相同
- 按ID从小到大顺序生成
- 根据数量范围随机生成

**生成规则**：
```
标记点：(10, 10)
数量：1-3个

可能生成位置：
- (8, 8) - 左上
- (10, 9) - 正上
- (12, 11) - 右下
- (9, 10) - 左侧
- ... 等等

范围：X轴 8-12, Y轴 8-12
```

**使用示例**：
```
1. 在地图上标记资源刷新点：
   - 位置(10,10): ID=1, 权重=10, 数量=1-3
   - 位置(20,20): ID=2, 权重=5, 数量=2-4

2. 加载Excel表

3. 点击"随机生成物件"

4. 结果：
   - 位置(10,10)周围生成1-3个ID=1的物体
   - 位置(20,20)周围生成2-4个ID=2的物体
   - 每个物体随机分布在±2格子范围内
```

## 🎮 操作说明

### 物体拖动操作
```
1. 标记模式 → 选择"无"
2. 点击地图上的物体 → 选中（黄色边框）
3. 按住物体拖动 → 移动到新位置
4. 点击空白处 → 取消选中
5. 在右侧属性面板 → 修改参数
```

### 标记资源刷新点
```
1. 标记模式 → "资源刷新点"
2. 设置参数：
   - 资源ID: 1
   - 权重: 10
   - 数量: 1-3
3. 在地图上标记
4. 格子显示：ID:1（绿色背景）
```

### 随机生成物件
```
1. 标记若干资源刷新点
2. 点击"加载Excel表"
3. 选择Excel文件
4. 点击"随机生成物件"
5. 物体在标记点周围随机生成
```

## 🔧 技术细节

### 物体拖动实现
```javascript
// 选中物体
onMouseDown() {
  const obj = getObjectAtGrid(gridX, gridY);
  if (obj) {
    this.selectedObject = obj;
    this.isDraggingObject = true;
  }
}

// 拖动物体
onMouseMove() {
  if (this.isDraggingObject) {
    this.draggedObject.gridX = newGridX;
    this.draggedObject.gridY = newGridY;
  }
}
```

### 随机位置计算
```javascript
// 在中心点附近随机偏移
const offsetX = Math.floor(Math.random() * 5) - 2; // -2到+2
const offsetY = Math.floor(Math.random() * 5) - 2;
const targetX = centerX + offsetX;
const targetY = centerY + offsetY;
```

## 📝 使用建议

### 建议工作流程
1. **准备阶段**
   - 选择资源目录
   - 新建地图或加载配置
   - 加载资源库

2. **标记阶段**
   - 标记不可移动点（建筑、障碍物）
   - 标记资源刷新点（怪物、道具）

3. **布置阶段**
   - 手动拖放重要物体（建筑、NPC）
   - 调整物体位置和参数

4. **随机生成**
   - 加载Excel表
   - 随机生成大量小物体（怪物、道具）

5. **调整优化**
   - 拖动物体微调位置
   - 修改物体参数
   - 删除不需要的物体

6. **保存配置**
   - 导出JSON配置文件

### 性能建议
- 地图物体建议控制在500个以内
- 随机生成前先预估总数量
- 大量物体时适当缩小地图查看
