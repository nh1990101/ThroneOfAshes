## 🎉 项目已完成！

一个功能完整的HTML5游戏地图编辑器，包含所有你要求的功能。

## 📦 快速开始

### 方式一：使用启动脚本（推荐）

**Windows:**
```bash
cd MapEditor
start.bat
```

**Linux/Mac:**
```bash
cd MapEditor
./start.sh
```

脚本会自动：
1. 检查Python环境
2. 可选转换Excel数据
3. 启动HTTP服务器
4. 打开浏览器

### 方式二：手动启动

```bash
cd MapEditor
python -m http.server 8080
# 访问 http://127.0.0.1:8080/launcher.html
```

## 🎯 使用流程

### 第一步：启动编辑器

打开 `http://127.0.0.1:8080/launcher.html`

系统会自动检查浏览器兼容性：
- ✓ 支持：显示绿色勾
- ✗ 不支持：显示红色叉，需要使用Chrome/Edge

### 第二步：选择资源目录

1. 点击工具栏的 **"选择资源目录"**
2. 选择项目的 `assets/remote` 目录（或项目根目录）
3. 编辑器会自动定位到remote目录
4. 状态栏显示：`当前: remote` 或类似名称

### 第三步：新建地图

1. 点击 **"新建地图"**
2. 填写配置：
   ```
   地图ID: Map1
   地图名称: 测试地图
   逻辑格子宽度: 32
   逻辑格子高度: 32
   ```
3. 选择地图资源类型：
   - **大地图JPG文件**: 选择大图，自动切割并保存
   - **已切割的地图块目录**: 填写路径加载

4. 点击 **"创建"**，等待处理完成

### 第四步：加载资源

点击 **"加载资源"**，编辑器自动扫描：
- `Res/Map/MapObject/Animation/` - 动画资源
- `Res/Map/MapObject/Image/` - 图片资源

左侧面板显示所有可用资源。

### 第五步：地图标记

#### 标记不可移动点
1. 标记模式 → **"不可移动点"**
2. 移动性 → **"不可移动"**
3. 操作 → **"长按"**（连续标记）或 **"单点"**（精确标记）
4. 在地图上拖动/点击标记
5. 右键取消标记

#### 标记资源刷新点
1. 标记模式 → **"资源刷新点"**
2. 设置参数：
   - 资源ID: `1`（对应Excel表的ID）
   - 权重: `10`
   - 数量: `1` - `3`（随机生成1-3个）
3. 在地图上标记
4. 同一格子可以标记多个不同ID

### 第六步：拖放物体

1. 从左侧资源列表拖动物体到地图
2. 点击地图上的物体选中它
3. 右侧属性面板修改：
   - 类型: `3`（建筑）
   - 占据格子X: `3`
   - 占据格子Y: `3`
   - 格子偏移X: `0`
   - 格子偏移Y: `0`
   - 类型参数: `（可选）`
4. 修改后自动更新

### 第七步：随机生成（可选）

1. 点击 **"加载Excel表"**
2. 选择 `sharedata/excel/S-地图表(MapData).xlsx`
3. 加载成功后显示记录数
4. 点击 **"随机生成物件"**
5. 系统自动：
   - 遍历所有资源刷新点
   - 按Excel配置的ID生成物体
   - 根据权重和数量范围随机
   - 检查占据格子是否可放置
   - 生成完成显示物体数量

### 第八步：保存配置

点击 **"保存地图"**，下载JSON配置文件。

### 第九步：加载配置（后续编辑）

点击 **"加载地图"**，选择之前保存的JSON文件，恢复编辑状态。

## 💡 重要概念

### 1. 地图切割 vs 逻辑格子

**地图切割（512×512）**
- 用于渲染优化
- 分块加载大地图
- 与逻辑无关

**逻辑格子（自定义，如32×32）**
- 用于行走逻辑
- 用于物体放置
- 用于AI寻路

**两者独立，互不影响！**

### 2. 物体占据格子规则

**以放置点为中心向四周扩展**

例如：3×3的物体放在(5, 5)
```
实际占据范围：
  X: 5 - floor(3/2) = 4  到  5 + 3 - floor(3/2) = 7
  Y: 5 - floor(3/2) = 4  到  5 + 3 - floor(3/2) = 7
  
即：(4,4), (5,4), (6,4)
    (4,5), (5,5), (6,5)  ← 放置点在这里
    (4,6), (5,6), (6,6)
```

### 3. 资源刷新点的多ID机制

**同一格子可以有多个资源ID**

- 每个ID独立配置权重和数量
- 显示时颜色叠加（半透明）
- 生成时各自独立随机

例如：格子(10, 10)标记了：
- ID=1, 权重=10, 数量=1-2
- ID=3, 权重=5, 数量=2-3

生成时：
- ID=1生成1或2个
- ID=3生成2或3个
- 总共生成3-5个物体

## ⚠️ 注意事项

### 浏览器要求
- ✅ Chrome 86+
- ✅ Edge 86+
- ❌ Firefox（不支持File System Access API）
- ❌ Safari（不支持File System Access API）

### 文件系统权限
- 首次使用需要授权
- 浏览器会记住授权
- 下次打开自动恢复
- 如果权限丢失，重新选择目录

### Excel表格式
- 第3行：表头
- 第6行开始：数据
- 必需列：属性名、中文索引、类型、地图占格子数、地图显示的资源路径

### 资源路径规范
- 所有路径相对于 `assets/remote/`
- 例如：`Res/Map/MapObject/Image/building_1`
- 不需要写扩展名，系统自动查找`.png`、`.jpg`等

## 🐛 常见问题

**Q: 浏览器提示不支持？**
A: 必须使用Chrome或Edge浏览器，Firefox和Safari不支持。

**Q: 选择资源目录后没有反应？**
A: 检查是否选择了正确的目录（assets/remote或项目根目录）。

**Q: 地图切割后找不到文件？**
A: 文件保存在 `assets/remote/Res/Map/MapGrid/{地图ID}/` 目录。

**Q: 加载资源显示为空？**
A: 确保MapObject目录下有资源文件，点击"加载资源"按钮。

**Q: 随机生成没有效果？**
A: 检查：1) 是否已加载Excel表 2) 是否已标记资源刷新点 3) 标记的格子是否可放置。

**Q: 物体位置不对？**
A: 物体占据格子是以放置点为中心的，检查occupyX和occupyY设置。

**Q: 权限授权丢失？**
A: 浏览器清除数据会丢失授权，重新点击"选择资源目录"。

**Q: 配置文件太大？**
A: 物体较多时配置文件会比较大，这是正常的。

## 🚀 性能建议

- **大地图**: 建议先切割后再加载（分块渲染更快）
- **物体数量**: 超过1000个物体可能影响性能
- **缩放操作**: 频繁缩放时稍有延迟是正常的
- **保存配置**: 物体较多时保存需要几秒钟
