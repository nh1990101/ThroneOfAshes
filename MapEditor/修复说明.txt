如何使用
──────────────────────────────────────────
1. 双击运行 START.bat（会自动打开浏览器）
   
2. 或手动启动：
   cd D:\Project\cocos\RPGCore\MapEditor
   python -m http.server 8080
   
3. 浏览器访问：http://localhost:8080

4. 点击"选择资源目录"
   → 选择：D:\Project\cocos\RPGCore

5. 点击"新建地图"
   → 选择"现有地图块"
   → 填写地图块目录路径
   
6. 现在应该能正常显示坐标了！
