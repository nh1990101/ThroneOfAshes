# 地图编辑器测试步骤

## 前置条件

✅ 本地服务器已启动（http://localhost:8080）
✅ 浏览器已打开编辑器页面

---

## 测试场景 1：从大图切割创建地图

### 步骤

1. **刷新页面**
   - 按 `F5` 或 `Ctrl+R`
   - 确保加载最新代码

2. **选择资源目录**
   - 点击顶部"选择资源目录"按钮
   - 选择项目根目录：`D:\Project\cocos\RPGCore`
   - 等待提示"项目资源目录已设置"

3. **新建地图**
   - 点击"新建地图"
   - 填写信息：
     - 地图ID：`TestMap1`
     - 地图名称：`测试地图1`
     - 格子宽度：`64`
     - 格子高度：`64`
   - 选择"从大图切割"
   - 点击"选择文件"，选择一张大地图图片
   - 点击"确定"

4. **验证地图显示**
   - ✅ 地图能正常显示在画布上
   - ✅ 鼠标移动时，底部显示：
     - `像素: (x, y)` - 数字正常，不是 NaN
     - `格子: (x, y)` - 格子坐标
     - `地图: WxH格 (WxH px)` - 地图尺寸

5. **测试坐标系统**
   - 移动鼠标到左下角：像素坐标应接近 `(0, 0)`
   - 移动鼠标到右上角：像素坐标应接近地图最大尺寸
   - Y坐标应该从下往上递增（符合Cocos坐标系）

## 测试场景 3：标记和物体操作

### 步骤

1. **加载地图**（使用场景1或2创建的地图）

2. **测试阻挡点标记**
   - 点击工具栏的"阻挡点"按钮（🚫）
   - 鼠标移动到地图上，应该看到红色方块预览
   - 点击添加阻挡点
   - ✅ 底部坐标信息正常显示
   - ✅ 红色方块正确显示在点击位置

3. **测试资源刷新点**
   - 点击工具栏的"资源点"按钮（💎）
   - 鼠标移动，应该看到蓝色方块预览
   - 点击添加资源点
   - ✅ 蓝色方块正确显示

4. **测试出生点**
   - 点击工具栏的"出生点"按钮（⭐）
   - 鼠标移动，应该看到绿色五角星预览
   - 点击添加出生点
   - ✅ 绿色五角星正确显示

5. **测试物体拖动**
   - 点击"添加物体"，选择一个资源
   - 点击地图添加物体
   - 拖动物体到新位置
   - ✅ 物体能正确跟随鼠标移动
   - ✅ 底部坐标信息实时更新

## 遇到问题？

1. **地图不显示**
   - 检查是否已选择资源目录
   - 检查地图块文件是否存在
   - 查看浏览器控制台错误信息

2. **Y坐标仍显示NaN**
   - 确保已刷新页面（Ctrl+Shift+R 强制刷新）
   - 检查浏览器控制台是否有缓存警告

3. **地图块路径找不到**
   - 确认路径格式：`Res/Map/MapGrid/MapID`
   - 检查目录下是否有 `x_y.png` 格式的文件

4. **性能问题**
   - 大地图可能需要一些时间加载
   - 查看浏览器控制台的加载进度
