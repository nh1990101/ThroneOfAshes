🗺️ RPG地图编辑器

独立的HTML5游戏地图编辑工具

⚠️ 浏览器要求
本编辑器需要使用 Chrome 86+ 或 Edge 86+ 浏览器，因为使用了 File System Access API。

主要功能

🖼️ 地图切割

自动切割大地图为512×512小块

📍 地图标记

标记不可移动点和资源刷新点

🎨 物体拖放

从资源库拖放物体到地图

🎲 随机生成

根据Excel配置随机生成物件

🔍 地图缩放

鼠标滚轮自由缩放视图

💾 配置保存

保存和加载地图配置文件

使用前准备

  • 准备好地图资源图片（JPG/PNG格式）
  • 准备好地图物体资源（放在 MapObject 目录）
  • 准备好地图表Excel文件（可选，用于随机生成）
  • 确保使用Chrome或Edge浏览器
