修复内容

快速测试
───────────────────────────────────────────
1. 刷新浏览器（Ctrl+Shift+R）

2. 加载地图，添加一个物体

3. 点击物体，打开属性面板

4. 测试偏移Y：

   输入 0   → 物体在格子中心 ✓
   输入 50  → 物体往上移动 ✓
   输入 100 → 物体继续往上 ✓
   输入 0   → 物体回到中心 ✓
   输入 -50 → 物体往下移动 ✓

预期结果
───────────────────────────────────────────
✓ offsetY = 正数 → 物体往上
✓ offsetY = 负数 → 物体往下
✓ offsetY = 0    → 物体在格子中心

如果还是反的，请检查
───────────────────────────────────────────
1. 是否强制刷新了浏览器？
2. 浏览器控制台是否有错误？
3. 是否有缓存问题？

技术细节
───────────────────────────────────────────
Canvas坐标系：Y向下（左上角为原点）
用户期望：Y向上（Cocos语义）
解决方案：应用偏移时用减法

  baseWorld.y - offsetY

这样：
  offsetY=10  → Canvas Y减小 → 视觉上往上 ✓
  offsetY=-10 → Canvas Y增大 → 视觉上往下 ✓
